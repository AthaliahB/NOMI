## How to Run on Any Windows PC

1. **Requirement**: Make sure **[Node.js](https://nodejs.org/)** (LTS version) is installed.
2. **Double-click `run.bat`**:
   - Automatically verifies Node.js is present.
   - Automatically installs required dependencies (`npm install`) if missing.
   - Automatically launches the server and opens your default browser at `http://localhost:3000/home.html`.
